# Mini Project Bahasa C — Rekap Kegiatan Mahasiswa

## Tentang Proyek
Program Rekap Kegiatan Mahasiswa adalah aplikasi berbasis console yang dibuat menggunakan bahasa C untuk mencatat dan menghitung durasi aktivitas harian mahasiswa.

Program ini membantu pengguna mengetahui total waktu aktivitas yang telah dicatat serta sisa waktu dalam satu hari, dengan batas maksimal 24 jam.

## Fitur
- Memasukkan nama mahasiswa.
- Menentukan jumlah aktivitas yang ingin dicatat.
- Menambahkan nama aktivitas secara bebas beserta durasinya.
- Memvalidasi durasi agar tidak melebihi batas waktu harian 24 jam.
- Menambahkan aktivitas yang terlupakan.
- Menampilkan laporan aktivitas harian, total waktu, dan sisa waktu.
- Memilih untuk membuat rekap baru atau keluar dari program.

## Teknologi
- Bahasa C
- Code::Blocks

## Struktur Proyek
- `main.c` — Source code utama program.
- `README.md` — Dokumentasi proyek.

## Cara Menjalankan
1. Buka proyek menggunakan Code::Blocks.
2. Buka file `main.c`.
3. Compile dan jalankan program.
4. Masukkan nama mahasiswa dan jumlah aktivitas.
5. Catat setiap aktivitas beserta durasinya.
6. Periksa laporan aktivitas harian yang ditampilkan.

## Aturan Program
- Durasi aktivitas harus lebih dari 0 jam.
- Total durasi aktivitas tidak boleh melebihi 24 jam.
- Jika durasi melebihi sisa waktu, pengguna harus memasukkan durasi yang valid.

## Tujuan Pembelajaran
Mini project ini dibuat untuk menerapkan konsep dasar pemrograman C, seperti variabel, input dan output, percabangan, perulangan, array, serta validasi input.
